# 陆悦页

我的AI coding启蒙，一个主要借助**Gemini**从零开始构建的浏览器主页。

## ✨ 功能特性

- 🕒 **全能时钟与天气**：支持多时区无缝切换，内置公历、农历与节假日自动换算显示；集成高德实时天气预报，支持三级联动精确选择城市并带有缓存节流机制。
- 🔍 **聚合搜索栏**：悬浮胶囊设计，支持 Google、Bing、百度无缝切换。
- 📰 **全球资讯流**：侧边栏按时间线自动聚合 BBC、纽约时报、奇克、少数派等海内外多源 RSS 图文新闻，支持每小时自动静默刷新。
- 🔖 **高级书签管理**：书签桌面图标排版，内置完整的增删改查（CRUD）管理面板与无限分类，支持 JSON 配置的一键导入/导出。
- 🎨 **极致个性化**：提供全局设置面板，可实时调节壁纸模糊度、遮罩颜色、部件透明度以及黑白文字发光主题，支持本地界面配置的完美 JSON 备份与恢复。
- ⚡ **黑科技图片引擎**：当新闻无原配封面时，秒级调用本地 HTML5 Canvas 与自定义字体智能绘制沉稳的文字版配图。
- 📱 **完美响应式**：PC 端宏大舒展，移动端自动转化为侧滑抽屉与单列流，随时随地保持优雅。

## 🛠️ 技术栈

- **前端核心**：纯原生 HTML5, CSS3 (CSS Variables, Flexbox, Grid 布局, Backdrop-filter 毛玻璃特效), Vanilla JavaScript (ES6+)。
- **数据存储**：Web `localStorage` API（实现用户设置与书签配置的本地持久化）。
- **字体排版**：Google Noto Serif SC(思源宋体), OPPO Sans, 江西拙楷。

## 🔌 调用的 API & 开源服务

- **天气接口**：高德地图 Web
- **新闻解析**：rss2json
- **每日壁纸**：[Bing-Wallpaper-Action](https://github.com/zkeq/Bing-Wallpaper-Action) (Bing 每日壁纸 API 接口)
- **图标抓取**：Google Favicon API
- **本地渲染引擎**：HTML5 Canvas API (用于实现新闻卡片零延迟的高雅兜底文字封面)
